## 5. Decisions

Decided 2026-11-03:

1. **Patch vs minor for behaviour fixes:** patch, unless the change breaks the API.
   Breaking changes are minor bumps under the pre-1.0 rules in `docs/STABILITY.md`.
   Applied: `electrical`, `heat-transfer`, `building-sys` went to 0.2.0.
2. **Umbrella `tpt-engineering`: published 0.1.0.** Its README and `docs/guide`
   show `tpt-engineering = { version = "0.1", features = [...] }` as the install path.
3. **`tpt-math-*` alignment.** The workspace pins `tpt-math-numeric`, `-linalg` and
   `-stats` to 0.2.0. Check after the wave: `cargo tree -d` on a fresh consumer
   project, to confirm one copy. Not yet run.

Still open:

4. **Cosim, mcp, wasm, py.** Recommendation: keep all four unpublished. `tpt-eng-mcp`
   depends on `tpt-eng-sheet`, which is now live, so its reason is weaker than before.
   Revisit cosim once its trait is stable.
5. **`cargo-semver-checks`.** Run on the 13 changed crates on 2026-11-03. It found
   `heat-transfer` but missed the return-type changes in `electrical` and
   `building-sys`. Treat `pub_api_diff.py` as the primary check.
