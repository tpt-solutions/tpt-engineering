# tpt-eng

Umbrella facade for the `tpt-eng3` engineering workspace (TPT Solutions). Re-exports
[`tpt-eng-geometry`], [`tpt-eng-mesh`], [`tpt-eng-nurbs`], [`tpt-eng-gdt`], and
[`tpt-eng-cad`] under one crate. Dual-licensed MIT OR Apache-2.0.

See the workspace [`README`](https://github.com/tpt-solutions/tpt-eng3) for the full
crate overview, examples, and licensing policy.
